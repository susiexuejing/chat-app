# EF-394 DEV quiz-account Unix HTTP adapter draft

Source contract: chat-app PR #215 exact `a7d98311fd5db4c922f7641ce34b8ac71cf6e82b`, `server/src/quiz-public/runtime.mjs` and `server/qa/ef394-pnvs-offline/quiz-http-offline.mjs`. Candidate can be reviewed adjacent to `runtime.mjs`; no automatic import into the legacy or default server. No live credential, provider, request, publish or configuration change was used in this draft.

- Standalone no-argument entry expects exactly systemd's named inherited fd 3 (`ef-quiz-account-http`) for `/run/ef-quiz-account-dev/http.sock`. Actual path must be root-owned, no symlinks/alias paths, socket mode 0660 and immediate parent root-owned and not group/other-writable. Startup rejects TCP/address mismatch, performs bounded self-proof over the expected path, then and only then loads the account runtime. Inactive/missing/invalid window or disabled runtime closes and never opens TCP. Socket units and Nginx are not included.
- The host needs a **dedicated socket-only group**, with only the effective Nginx worker and dedicated quiz service identity enrolled. Socket parent must allow traversal by those identities. Do not grant the runtime broad existing Nginx group access just to make self-probe succeed. Verify the effective worker groups, exact inherited fd identity and ability to connect on the target; if safe group scoping is unavailable, leave the adapter off.
- Only exact /ceshi/api/auth/v1 challenge/verify (POST), result (GET/POST), logout (POST). Host and browser Origin are never fabricated. Use buffered fixed Content-Length UTF-8 JSON POST; chunked bodies, Expect/upgrade/CONNECT, conflicting/duplicate relevant headers, and unexpected method/path fail closed. No forwarded headers supply authority, session overrides, redirects, or arbitrary response headers. Runtime still owns account validation, consent, scoring, input fields and credential TTL.
- Only a validated Unix listener can open the request path. The same root-controlled QA plan supplies a nonrenewing <=15 minute adapter response window; if it closes before dispatch or after an awaited dispatch, return closed 404 and no report/cookie. The adapter cannot undo an already-dispatched underlying operation; runtime still owns the provider-time and database checks. Request data isn't logged.
- `node --test unix-http.test.mjs`: here 7 pass and 1 real local filesystem Unix test skipped due to AF_UNIX EPERM. No startup runtime/provider imports in tests. Real local test runs by default where socket binding is allowed. Set `EF_QUIZ_REQUIRE_UNIX_SMOKE=1` in CI to categorically fail rather than skip. Exact systemd inherited-descriptor and host Nginx forwarding/rights are **Not Run**, not covered by the simple listener test.
