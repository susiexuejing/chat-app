# EF-384：现有 Expo 应用内的合成闭环

关联 [EF-384](https://douhaoyu.atlassian.net/browse/EF-384)。实现基线为 dev `392161d20f86bb2d710a8cb6a25e32253dff6b5a`；业务规则参考 PR #160 `519b67ddc476751c43f76f439ddeb5ed75cee701`。本次是 React Native / Expo 页面与仓储移植，不加载独立 HTML、iframe 或 WebView，不继承独立 HTML 的 QA 结论。

## 运行边界

- 原有 `/` 和 `/chat` URL、原聊天页面和历史功能在 DEV 与其他构建中都保留。它们归属 `(live)` 路由组，共享该组布局中的真实 `ChatProvider`；根布局仅保留全局 Provider、global.css 和外层 Stack。
- `/demo` 是同一 Expo 应用内的原生兄弟路由，不是独立 HTML。仅 `EXPO_PUBLIC_APP_ENV=DEV` 开放合成页面；其他构建直接访问时明确显示不可用，不回退真实聊天。
- 原聊天首页和聊天页增加明确的“合成演示（不调用模型）”入口，水合未完成或正在处理真实发送时禁用入口。进入时使用 replace，离开原聊天组，而不是让真实 Provider 包住合成页面。直接打开 `/demo` 不挂载真实 ChatProvider，不启动其历史水合、会话恢复或发送请求。
- 合成页面提供“返回原聊天与历史”，先丢弃草稿和待用验证码，再 replace 回原入口。用户明确返回后恢复原聊天行为；不能声称整个 DEV 应用都不连接真实服务。
- 合成页面只使用独立仓储，不读取或改写 `chat_sessions`、真实会话或模型配置。数据不离开当前浏览器。
- 本阶段面向现有 DEV 网页。SSR 先显示加载状态，浏览器挂载后才访问 localStorage；本地存储不可用或非 Web 平台明确阻断，不降级到真实聊天或声称已持久化。
- 仅支持一个活动标签页。同步 localStorage 的单项写入保证同一次变更的聚合一致性；版本检查不等同于跨标签页事务锁，不声称多标签并发安全。

### 离开真实聊天时的异步边界

原聊天水合和后台历史同步需要生命周期取消保护。卸载后的迟到身份/存储读取不得再启动会话 GET 或新的水合恢复写入；已发出的会话 GET 应收到 AbortSignal，迟到结果不得覆盖状态。入口同时等待本地水合完成，且在真实发送处理中禁用。

不能撤回服务器已经接收的请求，也不能丢弃此前已接受的真实聊天持久化。DEV web 的匿名会话初始化在调用时同步发起，可能被其他真实调用共享，允许此类既有认证与持久化收尾；不因此继续发起历史 GET。本阶段不重写移动端 SecureStore 认证链，也不宣称移动端合成流程已经支持。

## 业务范围

使用虚构号码 `00000000000` 和当次页面显示的六位演示码，不发短信。固定合成聊天只生成待观察候选；拒绝、暂不确定、停止、离开与取消不保存候选或草稿。

一个模式对应一个可编辑/暂停的练习。记录按是否发生、实际动作和相关感受展开，保留“其他动作”和“不想记录感受”，跳过不写入，备注不必填。路径回看显示明确保存的事实、来源、记录和理解修正；感受/说明可编辑，移除关联须确认。例外类型的显示与可由用户创建例外的能力分开，本次不新增例外创建流程。

仓储以带版本的独立聚合保存本地演示账户、会话、模式、练习、记录与路径。理解变化和旧/新理解历史一次提交，记录和路径关联一次提交。失败不会把部分结果当成功，草稿由页面保留以便重试；取消与退出清空未保存界面状态。操作标识用于重复记录提交的幂等校验。已丢失的旧理解不会补造。

BQA-01：页面提示属于当前操作。开始新的操作、编辑或导航时清除旧成功提示；失败显示当前未保存状态，不能同时遗留旧“已保存”。

最初的 `4f7ef455` 候选在 DEV 替换了原入口，导致原聊天/历史不可达。此问题已记录，后续路由修正恢复原功能；该候选的技术 CI 不能代替修正后提交的复验。
